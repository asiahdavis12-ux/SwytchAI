Acceptable Use Policy

Last Updated: September 8, 2026

This Acceptable Use Policy ("AUP") governs the use of SwytchAI. Violations may result in suspension or termination of your account.

1. Authorized Use Only

You may only use SwytchAI to manage network devices that you own or have explicit written authorization to manage. Unauthorized access to any network device through SwytchAI is strictly prohibited.

2. Prohibited Activities

  • Using SwytchAI to gain unauthorized access to networks or devices
  • Pushing malicious configurations designed to disrupt network operations
  • Sharing account credentials with unauthorized individuals
  • Attempting to bypass plan limits or access controls
  • Using the API to perform automated attacks or abuse
  • Storing illegal content or using the Service for illegal purposes
  • Reselling or redistributing the Service without written permission
  • Intentionally overloading or disrupting the Service

3. Credential Security

You are responsible for the security of all device credentials stored in SwytchAI. We recommend:

  • Using unique service accounts for SwytchAI connections
  • Regularly rotating device passwords
  • Using the principle of least privilege for device access
  • Enabling multi-factor authentication when available

4. Configuration Responsibility

All configuration changes pushed through SwytchAI are your responsibility. Always:

  • Review configurations before approving
  • Test changes in a lab environment first when possible
  • Use the approval workflow for all production changes
  • Maintain rollback plans for critical changes

5. Reporting Violations

If you become aware of any violations of this policy, please report them immediately to security@swytchai.net

6. Enforcement

Violations may result in:

  • Warning notification
  • Temporary suspension of account
  • Permanent termination of account
  • Reporting to law enforcement if applicable
