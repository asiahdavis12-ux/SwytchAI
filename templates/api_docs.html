📡 SwytchAI REST API Documentation

Integrate SwytchAI into your workflows with our REST API

🔐 Authentication

All API requests require an API key passed in the header:

X-API-Key: your_api_key_here

Generate your API key from the Dashboard → Settings page.

🌐 Base URL

https://swytchai.net/api

📋 Endpoints

GET /api/health Check API status

Response:

{ "app": "SwytchAI", "status": "running", "version": "4.2" }
GET /api/devices List all devices

Headers:

X-API-Key: your_api_key

Response:

{ "devices": [ { "device_id": 1, "hostname": "core-switch-01", "host": "192.168.1.1", "vendor": "cisco_ios" } ] }
GET /api/devices/{id}/facts Get device facts

Response:

{ "hostname": "core-switch-01", "vendor": "Cisco", "model": "CSR1000V", "os_version": "17.3.4a", "serial": "9ABCDEFG123", "uptime": 1234567 }
GET /api/devices/{id}/config Pull running config

Response:

{ "hostname": "core-switch-01", "config": "! Running configuration...\nhostname core-switch-01\n..." }
POST /api/changes Propose a config change

Request Body:

{ "host": "core-switch-01", "description": "Add VLAN 200", "config_lines": [ "vlan 200", "name ENGINEERING" ] }

Response:

{ "message": "Change proposed", "change_id": 1, "status": "PENDING" }
GET /api/changes List all config changes

Query Parameters:

?status=PENDING

Response:

{ "changes": [ { "change_id": 1, "host": "core-switch-01", "description": "Add VLAN 200", "status": "PENDING", "proposed_by": "admin" } ] }
